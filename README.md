# Tháng Mười thương · 20/10

Thiệp chúc mừng Ngày Phụ nữ Việt Nam dành cho các bạn nữ trong nhóm.

- Bó hoa minh họa chuyển động, hiệu ứng cánh hoa rơi.
- Thư tiếng Việt ẩn trong biểu tượng phong thư; bấm để đọc và gấp lại.
- Nhạc nền nhẹ bằng Web Audio, có nút bật/tắt. Trang thử tự phát nhạc; nếu trình duyệt chặn, nhạc bắt đầu sau lần chạm đầu tiên.
- Giao diện responsive và nút chia sẻ đường link.

## Chạy thử

Mở `index.html` trong trình duyệt hoặc dùng một máy chủ web tĩnh. Không cần cài thư viện hay bước build. Phông chữ Google Fonts có phông dự phòng khi ngoại tuyến.

## Xuất bản bằng GitHub Pages

Trong kho GitHub, vào **Settings → Pages**. Tại **Build and deployment**, chọn **Deploy from a branch**, nhánh **main**, thư mục **/ (root)** rồi **Save**. Khi GitHub triển khai xong, dùng đường link được hiển thị trong phần Pages để chia sẻ.
